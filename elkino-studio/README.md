# Elkino Studio

The website is plain HTML, CSS and JavaScript. Serve `dist/` over HTTP and open its index.

## Add or update a film

Edit `dist/works.js`. Each film has a unique slug, title, series, theme, image filename, alternative text, YouTube URL, description, and related film slugs. Put a 16:9 image in `dist/assets/`. The archive uses the order in this file. Use `newest: true` for the latest featured film. Film links use `?work=<slug>`. To change the front-page feature, update the hero link in `dist/index.html`.

The KOMOREBI and BORO assets come from their mono Japan YouTube videos. The forest and TAYUTAU images are atmospheric photographs from Unsplash.
